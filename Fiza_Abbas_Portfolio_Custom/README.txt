# Fiza Abbas Portfolio

## Run it in VS Code
1. Extract `Fiza_Abbas_Portfolio.zip`.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in your browser, or install the VS Code extension **Live Server** and choose **Open with Live Server**.

## Personalize before sharing
- Your uploaded photo is already included as `assets/fiza-abbas.jpg`. Replace this file if you want to use another photo later.
  `<img class="profile-photo" src="assets/fiza.jpg" alt="Fiza Abbas">`
  Then add this to `style.css`:
  `.profile-photo{width:100%;height:100%;object-fit:cover;border-radius:50%;border:5px solid #0b1120}`
- Add your actual LinkedIn and GitHub profile URLs to the social links.
- Replace sample project cards with your real projects and project links.
- Confirm whether 2024 is your graduation/completion year and edit the wording if needed.
- The internship card is intentionally general because no employer, role, or dates were provided.

## Publish and get a shareable link with GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a new public repository named `fiza-abbas-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish. The shareable link will look like `https://YOUR-USERNAME.github.io/fiza-abbas-portfolio/`. Replace `YOUR-USERNAME` with your actual GitHub username and use the exact URL shown in Settings → Pages.

The final URL cannot be made live until you publish it in your own GitHub account.
